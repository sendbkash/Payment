# XE66 Demo — Game Lobby (বাংলা নির্দেশিকা)

এটি একটি **front-end demo template**। ডিজাইনটি তোমার দেওয়া স্ক্রিনশট থেকে অনুপ্রাণিত: মাঝখানে প্রায় 486px mobile-style layout, উপরে header ও promotional banners, provider tabs, 4-column game grid এবং নিচে fixed navigation।

## ফাইল
- `index.html` — ওয়েবসাইটের পেজ ও কনটেন্ট
- `styles.css` — রং, সাইজ, responsive layout ও game card design
- `app.js` — filter, search, favorite, language toggle, menu ও demo modal-এর interaction

## Browser-এ চালানো
1. ZIP Extract করো।
2. `index.html` ফাইলটি Chrome-এ খোলো।
3. কোনো software বা package install করার প্রয়োজন নেই।

## GitHub Pages-এ প্রকাশ করা
1. GitHub-এ একটি নতুন public repository তৈরি করো।
2. এই ZIP extract করে ভেতরের তিনটি website file (`index.html`, `styles.css`, `app.js`) এবং `README_BN.md` repository-তে upload করো।
3. Repository → **Settings** → **Pages** খোলো।
4. **Deploy from a branch** নির্বাচন করো; Branch হিসেবে `main`, folder হিসেবে `/ (root)` দিয়ে Save করো।
5. কিছুক্ষণ পর GitHub Pages URL তৈরি করবে।
